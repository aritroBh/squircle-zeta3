# Scripts of the proofs supplement

These are the checks that the written proofs supplement of the paper runs.
They are named by group, g1 to g9, after the groups of sections of the supplement.
The supplement itself (the written proofs) is not in this repository.

Each script was written to run in the research tree, so some need their paths adjusted.
`*.out` files are the stored outputs of the runs. The `.tex` fragments that some scripts read are not included.
