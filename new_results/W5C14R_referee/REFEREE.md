## 2. The three new atoms (hand check)

b = √2−1, a = 1/b, b/a = b².
- Li_5(b⁴), with t = (v/a)²: dt/t = 2 dlog v and dt/(1−t) = −dlog(v−a) − dlog(v+a); v: 0→b gives t: 0→b⁴.
- Li_5((4−3√2)/8), with w = s/(s−1), s = (v/a)²: dw/w = 2 dlog v − dlog(v−a) − dlog(v+a) and dw/(1−w) = dlog(v−a) + dlog(v+a); w runs over the real segment 0→b⁴/(b⁴−1) = (4−3√2)/8 < 0.
- Li_5(1−b⁴), with t = 1−s: dt/t = dlog(v−a) + dlog(v+a) and dt/(1−t) = −2 dlog v; v: a→b.

All forms and endpoints agree with s04 (outer→inner).

Convergence:
- In each case the innermost form is regular at the start point (v = 0, resp. v = a), and the outer forms are regular at v = b.
- So each integral converges as an ordinary improper integral. The singular outer dlog(v−a) at the start of the a→b path is harmless, because the inner integrals vanish to first order there.
- v ↦ t has derivative ∓2v/a² ≠ 0 on each segment, so the change of variables is valid for these convergent integrals.
- On [b, a] the point v = 1 is in the configuration but is not a letter of these forms.
- Under the Cayley map the segments become arcs through no letter. cmzv's radial path via 0 is homotopic to them inside the disk.
- That cmzv's regularised path value equals this convergent value is part of the conversion hypothesis.

## 4. Independent span test (r05)

Generators:
- L: 94762 std rows (W5C1 data) and 121630 lift rows (my regeneration), 216392 rows in all.
- e ш G: G = 5042 T0[S] rows plus 94 weight-4 lifts of the 13 A3h4 frame rows; 1200 random combinations.
- F: the 33 literally used frame-w5 rows.
- U: the 74 images u.f_i (my own action).

Method:
- Project each generator to the ± eigenspaces of u = 7. Because L ∪ 7.L, G ∪ 7.G, F ∪ 7.F and U are 7-stable, membership in the full span is equivalent to membership of both projections.
- Take n+64 random sparse combinations of the projected L rows. Every membership found is sound; randomness can only cause false negatives.
- Run my own blocked elimination mod p with the test rows carried along. Then decide membership on the residues modulo span(L).

| 4194301 | + | 23382 | 23113 | 269 | 7 / 39 / 44 / 69 / 74 | eG+F+U only (not L, L+eG, L+eG+F, L+eG+U, L+F+U) | eG+F+U only |

Ranks agree at both primes and with W5G2R's r02 (23113 / 22993).

Controls in the + sector (both primes), each outside every span tested:
- Δ_rat + a unit vector;
- Δ_rat + vec(Li5(b⁴));
- Δ_sq + vec(Li5((4−3√2)/8));
- Δ_sq + vec(Li5(1−b⁴));
- Δ_rat − vec(Li5(b));
- a random vector.

Controls in the − sector:
- unit-vector and random controls: outside, as they should be;
- the four controls that add the vector of a real Li_5 value: **inside**.

**This is expected, and those four are not valid controls in the − sector.** The projection v ↦ v − 7.v sends a vector with value z to one with value z − z̄ = 2i·Im z. Here 7 acts on words as complex conjugation, so H(7.w) = conj H(w), and the vectors have rational coefficients. Every atom vector here has a real value, so its − projection has value 0. It is a true relation, and a complete span of proved relations in that sector should contain it. This is consistent with the numbers: every atom vector's imaginary part is ≤ 5e-15 with my evaluator (r02).

So the − sector half of the test shows that the conjugation-odd part of Δ is a combination of proved relations, which the proof does need. It carries **no** information about whether R_14, R_5 or the three new conversions are right, because any real-valued vector passes. **The evidence for the identity itself is entirely in the + sector.** There, the claim needs all three of e ш G, F and U (each smaller span fails), and all six controls fail.

The b⁴ duplication check: Li5(b⁴) − 256 Li5(b) − 256 Li5(−b) − 16 Li5(−b²) lies in the relation span mod both primes. This is an independent consistency check of the b⁴ pullback vector against the cross-ratio conversions. No such simple check exists for the other two new atoms.

What the test shows: Δ is in span(L ∪ 7.L) + e ш span(G ∪ 7.G) + span(F ∪ 7.F) + span(U) modulo 4194301 and 4194287. Over Q, membership would give Δ·V = 0 under the standing hypotheses, because every generator is a proved relation (U by W5G2). A mod-p result is strong evidence for, but not a proof of, membership over Q. The proof over Q is W5C14's exact s07–s10.
